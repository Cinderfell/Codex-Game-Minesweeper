# 扫雷俱乐部

简体中文扫雷网页游戏，包含自定义棋盘、昵称密码账号、全球榜和邀请码群组榜。

## 本地运行

1. 安装 Node.js 20 或更新版本，以及 pnpm。
2. 在 Supabase 创建项目，在 SQL Editor 执行 `supabase/migrations/202610190001_initial_schema.sql`。在 Authentication 中启用密码登录；应用通过服务端管理接口创建已确认账号，不会给用户发送邮件。
3. 复制 `.env.example` 为 `.env.local`，填入项目 URL、anon key 和 service role key。service role key 只用于服务端，不能添加 `NEXT_PUBLIC_` 前缀。
4. 执行 `pnpm install`，然后 `pnpm dev`，打开终端显示的本地地址。

## 昵称登录说明

Supabase Auth 负责安全保存密码哈希和签发会话。应用不要求或收集邮箱；服务端把昵称转换成不可登录的内部别名交给 Supabase Auth 使用，并在创建账号时直接确认该账号，因此无需邮件或验证码。注册后的昵称无法自行更改，首版也不支持密码找回。

昵称长度为 3–18 个 Unicode 字符，不能包含空白或控制字符；大小写不敏感且必须唯一。密码为 8–72 个字符。

## 数据与排行

排行榜收录初级（9×9、10 雷）、中级（16×16、40 雷）和专家（16×30、99 雷）胜局，按完成用时升序排列。自定义棋盘只供本地游玩。群组使用邀请码加入；群组排行根据当前成员的固定难度成绩生成。首版是休闲排行，成绩由客户端计时，服务端会验证账号、难度和用时范围，但不验证完整扫雷操作过程。
